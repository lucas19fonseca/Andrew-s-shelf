# 📚 Meu Primeiro Site de Livros

🔍 **Visão Geral**  

Este projeto é um site de livros simples desenvolvido como parte do meu aprendizado no 3º semestre de **Ciências da Computação** no **UniCEUB**. Ele foi construído utilizando **HTML**, **CSS**, e **JavaScript**, permitindo que os usuários explorem uma lista de livros e visualizem seus detalhes. O foco principal foi aprender e praticar a construção de uma interface web básica. 

Embora o projeto ainda esteja em evolução, ele já oferece uma interface funcional com listagem de livros. Há muitas oportunidades de melhorias e novas funcionalidades a serem implementadas.

🚀 **Tecnologias Utilizadas**
- **HTML5**: Para a estruturação das páginas do site.
- **CSS3**: Para a estilização e layout responsivo do site.
- **JavaScript**: Para adicionar interatividade básica à página.

💡 **Melhorias Futuras**
- Adicionar um sistema de login para usuários.
- Implementar um banco de dados para armazenar e gerenciar os livros dinamicamente.
- Melhorar a responsividade e a acessibilidade da interface.
- Criar uma funcionalidade de busca por título ou autor.
- Adicionar um sistema de avaliações e comentários para os livros.
