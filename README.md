## Descrição
> Um site de livros desenvolvido em HTML, CSS e JavaScript como parte do aprendizado no 3º semestre de Ciências da Computação no UniCEUB. Ainda em progresso, com muitas melhorias a serem feitas.
Este site foi desenvolvido com o objetivo de praticar HTML, CSS e JavaScript no curso de **Ciências da Computação** no **UniCEUB**. A ideia central é permitir que os usuários possam ver uma lista de livros, seus detalhes e filtrar por categorias. 

O projeto faz parte do meu processo de aprendizado, e reconheço que há várias áreas para melhorias e novos recursos que podem ser implementados no futuro.
