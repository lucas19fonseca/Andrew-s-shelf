
# 📚 Meu Primeiro Site de Livros

🔍 **Visão Geral**  

Este projeto é um site de livros simples desenvolvido como parte do meu aprendizado no 3º semestre de **Ciências da Computação** no **UniCEUB**. Ele foi construído utilizando **HTML**, **CSS**, e **JavaScript**, permitindo que os usuários explorem uma lista de livros e visualizem seus detalhes. O foco principal foi aprender e praticar a construção de uma interface web básica. 

Embora o projeto ainda esteja em evolução, ele já oferece uma interface funcional com listagem de livros. Há muitas oportunidades de melhorias e novas funcionalidades a serem implementadas.No fim,estou guardando esse projeto para eu ver minha evolução mais a frente.

🚀 **Tecnologias Utilizadas**
- **HTML5**: Para a estruturação das páginas do site.
- **CSS3**: Para a estilização e layout responsivo do site.
- **JavaScript**: Para adicionar interatividade básica à página.
